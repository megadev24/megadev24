
# Hey, I'm Frederick 👋

Most of my professional experience is in front-end development with React and TypeScript. Outside of work, I spend a lot of time building games, experimenting with backend systems, and occasionally making things more complicated than they need to be.

## What I'm working on

### Enveloped in Darkness
A narrative-driven horror game I'm building in Godot with C#. I'm particularly interested in creating a world that reacts to what players do rather than relying entirely on scripted events.

### TCGOK
A platform I've been building for the One Piece TCG community, with tournament management, rankings, player statistics, and community integrations.

Built with Next.js, TypeScript, Supabase, and Stripe.

### OPBoard
A One Piece TCG simulator I'm developing in Unity with C#. Most of the interesting challenges involve translating complex card game rules into reliable game systems.

### Contrabot
My ongoing experiments with AI agents, development automation, custom MCP servers, and self-hosted tools. It's also an excuse to learn more about infrastructure and how different systems fit together.

## Things I work with

- **Web:** TypeScript, JavaScript, React, Next.js, HTML, CSS
- **Backend:** Node.js, PostgreSQL, Supabase
- **Game Development:** C#, Godot, Unity
- **Other:** Docker, Git, Linux, Raspberry Pi
